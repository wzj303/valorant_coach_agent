# 本地知识数据

这些数据用于 VALORANT 教练原型的加载、未知状态处理和字段契约开发。所有数据记录均标记为 `source_status = "unverified"`，游戏版本 `patch` 为 `null`。

## 数据文件

- [经济规则](<game_rules/economy.json>) 包含武器、护甲和经济规则的初始词汇。价格、护甲数值及经济奖励均为 `null`。技能列表为空，表示尚未收录。
- [经济数据 Schema](<game_rules/schema.json>) 使用 JSON Schema Draft 2020-12，约束当前占位数据格式。
- [Sunset 地图](<maps/sunset/map.json>) 包含少量待核实区域名称。坐标、坐标系及地图图片链接为 `null`，邻接关系、视线和战术标注状态为 `unknown`。
- [Sunset 数据 Schema](<maps/sunset/schema.json>) 约束当前占位地图格式。

## 来源说明

本次未访问网络，也未查阅官方补丁说明、游戏客户端、地图图像或其他外部资料。词汇由本地编写，完整性和当前版本适用性均待核实。数据中的 `provenance` 记录本地来源类型、来源说明，以及待补充的来源 URL、检索时间、核实时间和核实方法。所有记录继承所属数据集的来源信息。

Schema 内的标准标识 URL 用于声明 JSON Schema 版本。它们属于格式元数据。地图来源 URL 和图片 URL 均留空。

## 消费约定

- `null` 表示未知。加载器必须保留未知值，计算预算时需要显式返回未知或缺失数据状态。
- 空数组表示尚未收录。尤其是空 `edges`、`sightlines` 和 `tactical_annotations`，使用时应同时读取相应的 `unknown` 状态。
- 名称、分类和区域 ID 是可供原型使用的待核实词汇，后续应基于目标版本核对。
- 经济数值、地图拓扑、视线、距离、行走时间和站位优势结论均需要补充来源并核实后才能提供确定性建议。
- 当前 Schema 刻意约束未知数值为 `null`，空关系集合保持为空。引入核实值时应同步升级 Schema、数据版本和消费者契约，并保留逐项来源及版本适用范围。

## 本地检查

可以使用 Python 标准库解析全部 JSON 文件，检查语法。如果环境安装了 `jsonschema`，还可以离线使用对应目录下的 Schema 校验每个数据文件。Schema 的 `$schema` 指向标准版本声明，实际数据文件的 `$schema` 指向相邻本地文件。
